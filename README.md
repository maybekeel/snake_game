# Snake Game

Console Snake game written in C++17.

## Build

```sh
cmake -S . -B build
cmake --build build
```

## Run

```sh
./build/snake_game
```

## Controls

Use the arrow keys to move the snake.

## Goal

Eat food to grow the snake. The game ends when the snake hits a wall or itself.
If the snake fills the whole board, the game is complete.
